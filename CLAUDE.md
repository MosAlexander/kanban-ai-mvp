# Веб-приложение MVP для управления проектами

## Бизнес-требования

В рамках этого проекта разрабатывается приложение для управления проектами. Ключевые особенности:
- Пользователь может войти в систему
- После входа в систему пользователь видит доску Канбан,представляющую его проект
- Доска Канбан имеет фиксированные столбцы, которые можно переименовывать
- Карточки на доске Канбан можно перемещать с помощью перетаскивания и редактировать
- В боковой панели есть функция чата с ИИ; ИИ может создавать/редактировать/перемещать одну или несколько карточек

## Ограничения

В MVP будет только один вход пользователя (жестко заданы «пользователь» и «пароль»), но в будущем база данных будет поддерживать несколько пользователей.

В MVP будет только одна доска Канбан на каждого вошедшего в систему пользователя.

Для MVP это будет работать локально (в контейнере Docker)

## Технические решения

- Фронтенд на NextJS
- Бэкенд на Python FastAPI, включая обслуживание статического сайта NextJS по адресу /
- Все упаковано в контейнер Docker
- Используйте "uv" в качестве менеджера пакетов для Python в контейнере Docker
- Используйте OPENAI_API_KEY для вызовов ИИ. OPENAI_API_KEY находится в файле .env в корне проекта
- Используйте openai/gpt-5-mini в качестве модели
- Используйте локальную базу данных SQLLite, создавая новую базу данных, если она не существует
- Скрипты запуска и остановки сервера для Mac, PC, Linux находятся в scripts/

## Отправная точка

Рабочий MVP фронтенда уже создан и находится во фронтенде. Он еще не предназначен для установки в Docker. Это чисто демонстрационный проект, ориентированный только на фронтенд.
